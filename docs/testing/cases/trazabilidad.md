Inventario de especificaciones de tests existentes, sin ejecuciones acreditadas
por este documento. Cada ID TC-TRAZA corresponde al test exacto de su última
columna; T5/T6 añaden los casos de límites y combinaciones de sus módulos sin
renumerar estos IDs. T7/T8/T9/T14 completan evidencia real; las plantillas no la
sustituyen. Fuentes: `docs/TRACEABILITY.md`, `docs/testing/README.md` y
`docs/testing/BACKLOG.md`. Responsable del inventario: Fabián Fuentes (P1).

probado; no copiar credenciales reales. Las entradas de la tabla resumen sus
escenarios. Los tests Deno y node:test cargan sus propios fixtures. Playwright
requiere Chromium y el servidor de prueba loopback de `tests/ui/serve-configuration.mjs`,
con API interceptada; no es una sesión de staging. Ejecutar con npm test o las
suites seleccionables de `scripts/test-all.mjs`. Toda ejecución real de casos se
anota por separado en `docs/testing/TEST_LOG.md` con commit, entorno y límites.
